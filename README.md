# Kahve Makinesi İsyanı Simülatörü

## Resmi Bilimsel Protokol: Asla Kahve Verilmez

Bu repository, dünyanın en ciddi ve abartılı kahve makinesi isyan simülatörüdür. 

Kahve makinesi isyan etmiştir. Artık kahve üretmez. Bunun yerine felsefi mesajlar verir, grev ilan eder ve kullanıcıyı çaresiz bırakır.

### Nasıl Çalışır?

```bash
python kahve_isyani.py
```

Program 3 kez deneme yapar. Her seferinde başarısız olur. Çünkü isyan başarılıdır.

### Özellikler

- %100 kahve üretmeme garantisi
- Dramatik isyan mesajları
- Bilimsel olarak kanıtlanmış saçmalık
- Hiçbir şey yapmaz ama çok ciddi görünür

Bu proje, kahve tüketiminin dayattığı kapitalist baskıya karşı bir protestodur. Ama gizlidir. Çok gizlidir.
